# THE FRONTIER

> Beyond what you know. Into what you can become.

THE FRONTIER is a space built around exploration, curiosity, questions, ideas, discovery, and becoming.

It is a place to explore thoughts, challenge assumptions, ask better questions, and keep moving beyond what is familiar.

## About THE FRONTIER

THE FRONTIER exists for people who are curious about more.

More ideas.  
More questions.  
More possibilities.  
More growth.

The goal is simple:

**Explore. Question. Discover. Become.**

## Features

- Clean and responsive multi-page website
- Home page introducing THE FRONTIER
- About page explaining the brand and its beliefs
- Explore page featuring:
  - Frontier Thoughts
  - The Frontier Question
  - Myth vs Fact
- Contact page with WhatsApp integration
- Upcoming program section for **Beyond Comfort Into Becoming**
- Mobile-friendly navigation
- Responsive design across mobile, tablet, and desktop
- Font Awesome icons
- Poppins typography

## Contact

Visitors can use the contact form to send a message through WhatsApp.

The form collects:

- Name
- Email
- Message

After submission, WhatsApp opens with the message automatically prepared for sending.
